# Lagos Struggle

built by samwissy

Subway Surfers–style endless runner set on Lagos streets. Dodge danfo and okada, collect naira, stack power-ups.

**Play:** open `index.html` or deploy on [Vercel](https://vercel.com).

## Controls

| Desktop | Mobile |
|--------|--------|
| ← → or A D | Swipe left / right |
| ↑ / Space | Swipe up or tap top |
| ↓ / S | Swipe down or tap bottom |
| P / Esc | Pause |

## Characters

Street Runner · Danfo Conductor · LASU Student · Suya Man

## Features

- 3-lane runner through Lagos streets  
- Jump & roll  
- Hazards: danfo, okada, keke, potholes, checkpoints, generators  
- Power-ups: shield, suya boost, naira magnet, double naira  
- Best score saved in the browser  

## Deploy on Vercel

1. Import this GitHub repo on [vercel.com/new](https://vercel.com/new)  
2. Framework preset: **Other**  
3. Click **Deploy** (static site — no build command needed)  

Or CLI:

```bash
npx vercel
```

## Local

```bash
# open in browser
start index.html
```
